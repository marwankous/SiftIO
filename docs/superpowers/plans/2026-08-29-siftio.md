# SiftIO Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship a local-first browser data vault that loads the user's CSV/JSON exports into an in-page DuckDB-wasm instance and exposes them to AI agents through dynamically registered WebMCP tools, with a live audit trail of everything the agent reads.

**Architecture:** A single-page Angular application with no backend of any kind. `DuckService` owns a duckdb-wasm instance loaded from jsDelivr; `VaultService` ingests files into DuckDB tables and persists raw bytes to IndexedDB; `McpService` mirrors the dataset list onto `navigator.modelContext`, registering and unregistering per-dataset tools as datasets come and go; `AuditService` records every tool invocation. All state flows through Angular signals, so the UI and the registered toolset stay in lockstep automatically.

**Tech Stack:** Angular 21 (standalone, zoneless, signals), TypeScript strict, Tailwind (via Angular CLI's native `--style tailwind`), Vitest, `@duckdb/duckdb-wasm@1.33.1-dev57.0`, `chart.js@4.5.1`, `idb-keyval@6.3.0`. Deployed as static assets to Cloudflare Pages.

**Spec:** `docs/superpowers/specs/2026-08-29-siftio-design.md`

**Live:** https://siftio.marouane-kouskous.workers.dev — Cloudflare static-asset Worker, config in `wrangler.jsonc`.

## Global Constraints

- **Deadline: 2026-09-03, 1:00 PM PDT.** Task 1 must produce a live deployed URL on day one; every later task redeploys on merge.
- **No backend, ever.** No API routes, no serverless functions, no server-side rendering. The deployed artifact is static files. If a task seems to need a server, it is wrong.
- **Pin `@angular/cli@21`.** The host has Node v24.11.1; Angular 21 needs `>=24.0.0` and works, Angular 22 needs `^24.15.0` and does not. The dev container (`compose.yaml`) ships Node v24.20.0, so Angular 22 *would* run there — but staying on 21 keeps the project buildable both on the host and in the container, and nothing in the plan needs an Angular 22 feature. Do not upgrade without a reason.
- **The dev container is optional, not required.** `docker compose up` serves on `http://localhost:4200`; `docker compose run --rm dev sh` gives a shell. Every command in this plan also runs on the host as-is. Use the container for a clean, reproducible toolchain; use the host if it is already working.
- **`@duckdb/duckdb-wasm` has no non-`-dev` release.** `1.33.1-dev57.0` is the current `latest` dist-tag. Pin that exact string. This is upstream convention, not a pre-release warning.
- **Angular 21 uses the 2025 file-naming style guide** — the root component is `app.ts`, not `app.component.ts`. Follow that convention for all generated files.
- **Vitest is Angular 21's default test runner.** Do not add Karma or Jest. Run tests with `npm test -- --watch=false`; target one file with `--include <path>`. With `--browsers` unset, tests run in jsdom under Node, so no browser is needed in CI or in the dev container.
- **All WebMCP contact stays inside `McpService`.** No other file may reference `navigator.modelContext`. The API may drift before the deadline; keep the blast radius to one file.
- **Feature-detect and fail soft.** The app must be fully usable with no agent attached and no WebMCP support present.
- **`MAX_ROWS = 1000`** is the hard cap on rows returned to an agent from any tool.
- **Licence: MIT.** Positioning line for all copy: *"Your data stays in the browser. Only the answers leave."*

### Deliberate simplifications of the spec

Two spec sections are implemented more cheaply than written. Both are improvements; implement the version described here.

1. **Spec §5 step 2–3 (parse + infer types).** Do not add a CSV parser. DuckDB reads CSV and JSON natively and infers column types itself, via `read_csv_auto` / `read_json_auto` over a registered file buffer. Schema comes back from `DESCRIBE`. This removes a dependency and an entire class of parsing bugs. What remains to unit-test is the mapping from DuckDB's type strings to SiftIO's `ColumnType`.
2. **Spec §4.1 (DuckService wasm wiring).** Do not bundle the wasm and worker through the Angular build. Use duckdb-wasm's `getJsDelivrBundles()` + `selectBundle()`, which fetches the correct bundle from the CDN at runtime and builds the worker from a blob URL. This retires the single largest risk in the spec. Only executable code loads from the CDN — no user data leaves the page, so the privacy claim is unaffected.

Create `src/app/core/sql-guard.ts`:

```ts
const FORBIDDEN = [
  'DROP', 'DELETE', 'INSERT', 'UPDATE', 'CREATE', 'ALTER', 'TRUNCATE',
  'ATTACH', 'DETACH', 'COPY', 'INSTALL', 'LOAD', 'EXPORT', 'IMPORT',
  'PRAGMA', 'SET', 'CALL', 'GRANT', 'REVOKE', 'VACUUM', 'CHECKPOINT',
];

/** Replace string literals and comments with spaces so keyword scanning
 *  cannot be fooled by `WHERE note = 'drop table t'`. */
function strip(sql: string): string {
  return sql
    .replace(/--[^\n]*/g, ' ')
    .replace(/\/\*[\s\S]*?\*\//g, ' ')
    .replace(/'(?:[^']|'')*'/g, ' ')
    .replace(/"(?:[^"]|"")*"/g, ' ');
}

export function assertReadOnlySql(sql: string): void {
  const raw = sql?.trim() ?? '';
  if (!raw) throw new Error('Query is empty.');

  const stripped = strip(raw).trim().replace(/;\s*$/, '');

  if (stripped.includes(';')) {
    throw new Error('Only one statement is allowed per query.');
  }

  const first = stripped.match(/^[a-z_]+/i)?.[0].toUpperCase() ?? '';
  if (first !== 'SELECT' && first !== 'WITH') {
    throw new Error(
      `Only SELECT queries are allowed. This one starts with ${first || 'nothing recognisable'}.`,
    );
  }

  for (const word of FORBIDDEN) {
    if (new RegExp(`\\b${word}\\b`, 'i').test(stripped)) {
      throw new Error(`${word} is not permitted. SiftIO is read-only.`);
    }
  }
}
```

```ts
import type { Column, ColumnType, SemanticRole } from './models';

const RESERVED = new Set([
  'select', 'from', 'where', 'table', 'order', 'group', 'join', 'union',
  'create', 'drop', 'insert', 'update', 'delete', 'index', 'view', 'all',
]);

export function sanitizeTableName(fileName: string): string {
  const base = fileName.replace(/\.[^.]+$/, '');
  let name = base
    .toLowerCase()
    .replace(/[^a-z0-9]+/g, '_')
    .replace(/^_+|_+$/g, '');
  if (!name) return 't';
  if (/^[0-9]/.test(name) || RESERVED.has(name)) name = `t_${name}`;
  return name;
}

export function mapDuckType(duckType: string): ColumnType {
  const t = duckType.toUpperCase();
  if (/BOOL/.test(t)) return 'boolean';
  if (/DATE|TIME/.test(t)) return 'date';
  if (/INT/.test(t)) return 'integer';
  if (/DEC|NUMERIC|DOUBLE|FLOAT|REAL/.test(t)) return 'number';
  return 'string';
}

const ROLE_PHRASE: Record<SemanticRole, string> = {
  amount: 'the amount column',
  timestamp: 'the timestamp column',
  category: 'a category column',
  identifier: 'a unique identifier',
  label: 'a human-readable label',
  none: '',
};

export function describeColumn(c: Column): string {
  const phrase = ROLE_PHRASE[c.role];
  return phrase ? `${c.name} (${c.type}, ${phrase})` : `${c.name} (${c.type})`;
}
```

Create `src/app/core/duck.ts`:

```ts
import { Injectable } from '@angular/core';
import * as duckdb from '@duckdb/duckdb-wasm';
import { MAX_ROWS, type QueryResult } from './models';

@Injectable({ providedIn: 'root' })
export class DuckService {
  private db?: duckdb.AsyncDuckDB;
  private conn?: duckdb.AsyncDuckDBConnection;
  private booting?: Promise<void>;

  init(): Promise<void> {
    this.booting ??= this.boot();
    return this.booting;
  }

  private async boot(): Promise<void> {
    const bundles = duckdb.getJsDelivrBundles();
    const bundle = await duckdb.selectBundle(bundles);
    const workerUrl = URL.createObjectURL(
      new Blob([`importScripts("${bundle.mainWorker!}");`], {
        type: 'text/javascript',
      }),
    );
    const worker = new Worker(workerUrl);
    const logger = new duckdb.ConsoleLogger(duckdb.LogLevel.WARNING);
    this.db = new duckdb.AsyncDuckDB(logger, worker);
    await this.db.instantiate(bundle.mainModule, bundle.pthreadWorker);
    URL.revokeObjectURL(workerUrl);
    this.conn = await this.db.connect();
  }

  private async c(): Promise<duckdb.AsyncDuckDBConnection> {
    await this.init();
    return this.conn!;
  }

  async query(sql: string): Promise<QueryResult> {
    const conn = await this.c();
    const table = await conn.query(`SELECT * FROM (${sql}) LIMIT ${MAX_ROWS + 1}`);
    const all = table.toArray().map((r) => JSON.parse(JSON.stringify(r.toJSON())));
    const truncated = all.length > MAX_ROWS;
    return {
      columns: table.schema.fields.map((f) => f.name),
      rows: truncated ? all.slice(0, MAX_ROWS) : all,
      truncated,
    };
  }

  async ingestFile(table: string, fileName: string, bytes: Uint8Array): Promise<number> {
    const conn = await this.c();
    await this.db!.registerFileBuffer(fileName, bytes);
    const reader = fileName.toLowerCase().endsWith('.json')
      ? `read_json_auto('${fileName}')`
      : `read_csv_auto('${fileName}')`;
    await conn.query(`CREATE OR REPLACE TABLE "${table}" AS SELECT * FROM ${reader}`);
    const res = await conn.query(`SELECT count(*)::BIGINT AS n FROM "${table}"`);
    return Number(res.toArray()[0].toJSON()['n']);
  }

  async describeTable(table: string): Promise<{ name: string; duckType: string }[]> {
    const conn = await this.c();
    const res = await conn.query(`DESCRIBE "${table}"`);
    return res.toArray().map((r) => {
      const o = r.toJSON() as Record<string, unknown>;
      return { name: String(o['column_name']), duckType: String(o['column_type']) };
    });
  }

  async dropTable(table: string): Promise<void> {
    const conn = await this.c();
    await conn.query(`DROP TABLE IF EXISTS "${table}"`);
  }
}
```

Three things worth understanding here. `query()` wraps the caller's SQL in a subquery with `LIMIT MAX_ROWS + 1` — fetching one extra row is how `truncated` is detected without a second count query. The `JSON.parse(JSON.stringify(...))` round-trip converts Arrow's `BigInt` values into numbers, which would otherwise throw when serialised into a tool response. `registerFileBuffer` puts the file in DuckDB's virtual filesystem, entirely in memory.

```ts
import type { AuditEntry } from './models';

const CAP = 200;

@Injectable({ providedIn: 'root' })
export class AuditService {
  private readonly _entries = signal<AuditEntry[]>([]);
  readonly entries = this._entries.asReadonly();

  readonly rowsSeen = computed(() =>
    this._entries().reduce((n, e) => n + e.rows, 0),
  );
  readonly callCount = computed(() => this._entries().length);

  record(tool: string, args: unknown, rows: number, ms: number, error?: string): void {

      tool,
      args,
      rows,
      bytes: new TextEncoder().encode(JSON.stringify(args ?? {})).length,
      ms,
      at: Date.now(),
      error,
    };
    this._entries.update((list) => [entry, ...list].slice(0, CAP));
  }

  clear(): void {
    this._entries.set([]);
  }
}
```

```ts
import { Injectable, computed, inject, signal } from '@angular/core';
import { get, set, del, entries } from 'idb-keyval';
import { DuckService } from './duck';
import { mapDuckType, sanitizeTableName } from './schema';
import type { Column, Dataset, SemanticRole } from './models';

interface StoredDataset {
  meta: Dataset;
  bytes: Uint8Array;
}

@Injectable({ providedIn: 'root' })
export class VaultService {
  private readonly duck = inject(DuckService);
  private readonly _datasets = signal<Dataset[]>([]);
  readonly datasets = this._datasets.asReadonly();

  readonly rowsLocal = computed(() =>
    this._datasets().reduce((n, d) => n + d.rowCount, 0),
  );

  byId(id: string): Dataset | undefined {
    return this._datasets().find((d) => d.id === id);
  }

  async ingest(file: File): Promise<Dataset> {
    const lower = file.name.toLowerCase();
    if (!lower.endsWith('.csv') && !lower.endsWith('.json')) {
      throw new Error('SiftIO reads csv or json files.');
    }
    const bytes = new Uint8Array(await file.arrayBuffer());
    const meta = await this.load(file.name, bytes);
    await set(`ds:${meta.id}`, { meta, bytes } satisfies StoredDataset);
    return meta;
  }

  private async load(fileName: string, bytes: Uint8Array): Promise<Dataset> {
    const table = this.uniqueTable(sanitizeTableName(fileName));
    const vfsName = `${table}.${fileName.toLowerCase().endsWith('.json') ? 'json' : 'csv'}`;
    const rowCount = await this.duck.ingestFile(table, vfsName, bytes);
    const columns: Column[] = (await this.duck.describeTable(table)).map((c) => ({
      name: c.name,
      duckType: c.duckType,
      type: mapDuckType(c.duckType),
      role: 'none' as SemanticRole,
    }));
    const meta: Dataset = {
      id: table,
      table,
      fileName,
      rowCount,
      columns,
      ingestedAt: Date.now(),
    };
    this._datasets.update((list) => [...list, meta]);
    return meta;
  }

  private uniqueTable(base: string): string {
    const taken = new Set(this._datasets().map((d) => d.table));
    if (!taken.has(base)) return base;
    let i = 2;
    while (taken.has(`${base}_${i}`)) i++;
    return `${base}_${i}`;
  }

  async eject(id: string): Promise<void> {
    const ds = this.byId(id);
    if (!ds) return;
    await this.duck.dropTable(ds.table);
    await del(`ds:${id}`);
    this._datasets.update((list) => list.filter((d) => d.id !== id));
  }

  setRole(id: string, column: string, role: SemanticRole): void {
    this._datasets.update((list) =>
      list.map((d) =>
        d.id !== id
          ? d
          : {
              ...d,
              columns: d.columns.map((c) =>
                c.name === column ? { ...c, role } : c,
              ),
            },
      ),
    );
    const ds = this.byId(id);
    if (ds) void get<StoredDataset>(`ds:${id}`).then((s) =>
      s ? set(`ds:${id}`, { ...s, meta: ds }) : undefined,
    );
  }

  async rehydrate(): Promise<void> {
    const all = await entries<string, StoredDataset>();
    for (const [key, stored] of all) {
      if (!String(key).startsWith('ds:')) continue;
      const meta = await this.load(stored.meta.fileName, stored.bytes);
      for (const c of stored.meta.columns) {
        if (c.role !== 'none') this.setRole(meta.id, c.name, c.role);
      }
    }
  }
}
```

`load()` is shared by `ingest` and `rehydrate` so that a restored dataset goes through exactly the same DuckDB path as a fresh one. Roles are re-applied afterwards because `load()` always starts them at `none`.

```ts
import { MAX_ROWS, type Dataset } from './models';
import { describeColumn } from './schema';

const OPS = ['=', '!=', '<', '<=', '>', '>=', 'LIKE'] as const;
const AGGS = ['sum', 'avg', 'min', 'max', 'count'] as const;

export interface QueryToolInput {
  columns?: string[];
  where?: { column: string; op: string; value: unknown }[];
  groupBy?: string;
  aggregate?: { fn: string; column: string };
  orderBy?: string;
  descending?: boolean;
  limit?: number;
}

const numeric = (ds: Dataset) =>
  ds.columns.filter((c) => c.type === 'integer' || c.type === 'number')
    .map((c) => c.name);

export function buildQueryToolSchema(ds: Dataset): Record<string, unknown> {
  const names = ds.columns.map((c) => c.name);
  return {
    type: 'object',
    required: [],
    properties: {
      columns: {
        type: 'array',
        description: 'Columns to return. Omit for all columns.',
        items: { type: 'string', enum: names },
      },
      where: {
        type: 'array',
        description: 'Filters, combined with AND.',
        items: {
          type: 'object',
          required: ['column', 'op', 'value'],
          properties: {
            column: { type: 'string', enum: names },
            op: { type: 'string', enum: [...OPS] },
            value: {},
          },
        },
      },
      groupBy: { type: 'string', enum: names, description: 'Column to group by.' },
      aggregate: {
        type: 'object',
        description: 'Aggregation to apply when grouping.',
        required: ['fn', 'column'],
        properties: {
          fn: { type: 'string', enum: [...AGGS] },
          column: { type: 'string', enum: numeric(ds) },
        },
      },
      orderBy: { type: 'string', enum: names },
      descending: { type: 'boolean' },
      limit: { type: 'integer', minimum: 1, maximum: MAX_ROWS },
    },
  };
}

export function buildQueryToolDescription(ds: Dataset): string {
  return (
    `Query the "${ds.fileName}" dataset (${ds.rowCount} rows, held locally in ` +
    `the user's browser). Columns: ${ds.columns.map(describeColumn).join(', ')}.`
  );
}

function lit(v: unknown): string {
  if (v === null || v === undefined) return 'NULL';
  if (typeof v === 'number' || typeof v === 'boolean') return String(v);
  return `'${String(v).replace(/'/g, "''")}'`;
}

export function buildQuerySql(ds: Dataset, input: QueryToolInput): string {
  const known = new Set(ds.columns.map((c) => c.name));
  const col = (name: string): string => {
    if (!known.has(name)) throw new Error(`Unknown column: ${name}`);
    return `"${name}"`;
  };

  const parts: string[] = [];

  if (input.groupBy && input.aggregate) {
    const { fn, column } = input.aggregate;
    if (!AGGS.includes(fn as (typeof AGGS)[number])) {
      throw new Error(`Unsupported aggregate: ${fn}`);
    }
    parts.push(
      `SELECT ${col(input.groupBy)}, ${fn}(${col(column)}) AS "${fn}_${column}"`,
    );
  } else if (input.columns?.length) {
    parts.push(`SELECT ${input.columns.map(col).join(', ')}`);
  } else {
    parts.push('SELECT *');
  }

  parts.push(`FROM "${ds.table}"`);

  if (input.where?.length) {
    const clauses = input.where.map((w) => {
      if (!OPS.includes(w.op as (typeof OPS)[number])) {
        throw new Error(`Unsupported operator: ${w.op}`);
      }
      return `${col(w.column)} ${w.op} ${lit(w.value)}`;
    });
    parts.push(`WHERE ${clauses.join(' AND ')}`);
  }

  if (input.groupBy && input.aggregate) parts.push(`GROUP BY ${col(input.groupBy)}`);
  if (input.orderBy) {
    parts.push(`ORDER BY ${col(input.orderBy)}${input.descending ? ' DESC' : ''}`);
  }

  const limit = Math.min(Math.max(input.limit ?? MAX_ROWS, 1), MAX_ROWS);
  parts.push(`LIMIT ${limit}`);

  return parts.join(' ');
```

```ts
import { Injectable, signal } from '@angular/core';
import { get, set } from 'idb-keyval';
import type { ChartSpec, QueryResult, SavedView } from './models';

@Injectable({ providedIn: 'root' })
export class ViewportService {
  private readonly _result = signal<QueryResult | null>(null);
  private readonly _chart = signal<ChartSpec | null>(null);
  private readonly _views = signal<SavedView[]>([]);

  readonly result = this._result.asReadonly();
  readonly chart = this._chart.asReadonly();
  readonly views = this._views.asReadonly();

  constructor() {
    void get<SavedView[]>('views').then((v) => v && this._views.set(v));
  }

  show(result: QueryResult, chart: ChartSpec | null = null): void {
    this._result.set(result);
    this._chart.set(chart);
  }

  saveView(name: string, sql: string, chart: ChartSpec): SavedView {
    const view: SavedView = { id: crypto.randomUUID(), name, sql, chart };
    this._views.update((v) => [...v, view]);
    void set('views', this._views());
    return view;
  }

  removeView(id: string): void {
    this._views.update((v) => v.filter((x) => x.id !== id));
    void set('views', this._views());
  }
}
```

```ts
import { Injectable, computed, effect, inject, signal } from '@angular/core';
import { AuditService } from './audit';
import { DuckService } from './duck';
import { VaultService } from './vault';
import { ViewportService } from './viewport';
import { assertReadOnlySql } from './sql-guard';
import {
  buildQuerySql,
  buildQueryToolDescription,
  buildQueryToolSchema,
  type QueryToolInput,
} from './tool-schema';
import { getModelContext, type McpClient, type McpToolDef } from './webmcp';
import type { ChartKind, Dataset } from './models';

@Injectable({ providedIn: 'root' })
export class McpService {
  private readonly duck = inject(DuckService);
  private readonly vault = inject(VaultService);
  private readonly audit = inject(AuditService);
  private readonly viewport = inject(ViewportService);

  private readonly ctx = signal(getModelContext());
  private readonly _tools = signal<Map<string, McpToolDef>>(new Map());

  readonly available = computed(() => this.ctx() !== null);
  readonly toolNames = computed(() => [...this._tools().keys()].sort());

  init(): void {
    this.ctx.set(getModelContext());
    for (const tool of this.staticTools()) this.register(tool);

    effect(() => {
      const wanted = new Set<string>();
      for (const ds of this.vault.datasets()) {
        wanted.add(`query_${ds.table}`);
        wanted.add(`describe_${ds.table}`);
        for (const tool of this.datasetTools(ds)) {
          if (!this._tools().has(tool.name)) this.register(tool);
        }
      }
      for (const name of this.toolNames()) {
        if (name.startsWith('query_') || name.startsWith('describe_')) {
          if (!wanted.has(name)) this.unregister(name);
        }
      }
    });
  }

  /** Invoke a tool by name, bypassing the browser. Used by the MockAgent panel. */
  async invoke(name: string, input: unknown): Promise<object> {
    const tool = this._tools().get(name);
    if (!tool) throw new Error(`No such tool: ${name}`);
    return tool.execute(input);
  }

  // --- registration ----------------------------------------------------

  private register(tool: McpToolDef): void {
    const wrapped: McpToolDef = { ...tool, execute: this.wrap(tool) };
    this._tools.update((m) => new Map(m).set(tool.name, wrapped));
    try {
      this.ctx()?.registerTool(wrapped);
    } catch {
      // already registered after a hot reload — replace it
      try {
        this.ctx()?.unregisterTool(tool.name);
        this.ctx()?.registerTool(wrapped);
      } catch { /* give up quietly; the app still works */ }
    }
  }

  private unregister(name: string): void {
    this._tools.update((m) => {
      const next = new Map(m);
      next.delete(name);
      return next;
    });
    try { this.ctx()?.unregisterTool(name); } catch { /* not found */ }
  }

  /** Time every invocation, record it, and surface errors as tool results. */
  private wrap(tool: McpToolDef): McpToolDef['execute'] {
    return async (input, client) => {
      const started = performance.now();
      try {
        const out: any = await tool.execute(input, client);
        const rows = Array.isArray(out?.rows) ? out.rows.length : 0;
        this.audit.record(tool.name, input, rows, performance.now() - started);
        return out;
      } catch (err) {
        const message = err instanceof Error ? err.message : String(err);
        this.audit.record(tool.name, input, 0, performance.now() - started, message);
        return { error: message };
      }
    };
  }

  // --- static tools ----------------------------------------------------

  private staticTools(): McpToolDef[] {
    return [
      {
        name: 'list_datasets',
        description:
          'List every dataset currently loaded in the user\'s local SiftIO vault, ' +
          'with row counts and column schemas. Call this first to discover what is available.',
        annotations: { readOnlyHint: true },
        inputSchema: { type: 'object', properties: {}, required: [] },
        execute: async () => ({
          datasets: this.vault.datasets().map((d) => ({
            table: d.table,
            file: d.fileName,
            rows: d.rowCount,
            columns: d.columns.map((c) => ({ name: c.name, type: c.type, role: c.role })),
          })),
          rowsHeldLocally: this.vault.rowsLocal(),
        }),
      },
      {
        name: 'run_sql',
        description:
          'Run a read-only SQL SELECT against the local DuckDB vault. Tables are named ' +
          'by the `table` field from list_datasets. Use this to join across datasets. ' +
          `At most ${1000} rows are returned.`,
        annotations: { readOnlyHint: true },
        inputSchema: {
          type: 'object',
          required: ['sql'],
          properties: { sql: { type: 'string', description: 'A single SELECT statement.' } },
        },
        execute: async (input: { sql: string }, client?: McpClient) => {
          assertReadOnlySql(input.sql);
          await this.disambiguate(input.sql, client);
          const result = await this.duck.query(input.sql);
          this.viewport.show(result);
          return result;
        },
      },
      {
        name: 'render_chart',
        description:
          'Run a read-only SELECT and draw the result in the SiftIO viewport so the ' +
          'user can see it. Use after run_sql when a picture helps.',
        annotations: { readOnlyHint: true },
        inputSchema: {
          type: 'object',
          required: ['sql', 'kind'],
          properties: {
            sql: { type: 'string' },
            kind: { type: 'string', enum: ['bar', 'line', 'scatter', 'table'] },
            x: { type: 'string', description: 'Column for the x axis.' },
            y: { type: 'string', description: 'Column for the y axis.' },
          },
        },
        execute: async (input: { sql: string; kind: ChartKind; x?: string; y?: string }) => {
          assertReadOnlySql(input.sql);
          const result = await this.duck.query(input.sql);
          this.viewport.show(result, { kind: input.kind, x: input.x, y: input.y });
          return { rendered: true, ...result };
        },
      },
      {
        name: 'save_view',
        description:
          'Pin a named query and chart to the user\'s board so it survives after ' +
          'this conversation ends.',
        inputSchema: {
          type: 'object',
          required: ['name', 'sql', 'kind'],
          properties: {
            name: { type: 'string' },
            sql: { type: 'string' },
            kind: { type: 'string', enum: ['bar', 'line', 'scatter', 'table'] },
            x: { type: 'string' },
            y: { type: 'string' },
          },
        },
        execute: async (i: { name: string; sql: string; kind: ChartKind; x?: string; y?: string }) => {
          assertReadOnlySql(i.sql);
          const view = this.viewport.saveView(i.name, i.sql, { kind: i.kind, x: i.x, y: i.y });
          return { saved: view.id, name: view.name };
        },
      },
      {
        name: 'eject_dataset',
        description:
          'Remove a dataset from the local vault. The user is asked to confirm first.',
        annotations: { destructiveHint: true },
        inputSchema: {
          type: 'object',
          required: ['table'],
          properties: { table: { type: 'string' } },
        },
        execute: async (input: { table: string }, client?: McpClient) => {
          const ds = this.vault.datasets().find((d) => d.table === input.table);
          if (!ds) throw new Error(`No dataset named ${input.table}`);
          const ok = await this.confirm(
            `Remove "${ds.fileName}" (${ds.rowCount} rows) from your vault?`,
            client,
          );
          if (!ok) return { ejected: false, reason: 'The user declined.' };
          await this.vault.eject(ds.id);
          return { ejected: true, table: ds.table };
        },
      },
    ];
  }

  // --- dynamic per-dataset tools ---------------------------------------

  private datasetTools(ds: Dataset): McpToolDef[] {
    return [
      {
        name: `query_${ds.table}`,
        description: buildQueryToolDescription(ds),
        annotations: { readOnlyHint: true },
        inputSchema: buildQueryToolSchema(ds),
        execute: async (input: QueryToolInput) => {
          const current = this.vault.byId(ds.id);
          if (!current) throw new Error(`${ds.table} is no longer loaded.`);
          const result = await this.duck.query(buildQuerySql(current, input ?? {}));
          this.viewport.show(result);
          return result;
        },
      },
      {
        name: `describe_${ds.table}`,
        description:
          `Column statistics for "${ds.fileName}" — type, null count, distinct ` +
          'count, and min/max. Call this before querying to understand the data.',
        annotations: { readOnlyHint: true },
        inputSchema: { type: 'object', properties: {}, required: [] },
        execute: async () => {
          const result = await this.duck.query(`SELECT * FROM (SUMMARIZE "${ds.table}")`);
          return { table: ds.table, ...result };
        },
      },
    ];
  }

  // --- elicitation -----------------------------------------------------

  /** Ask the human when a bare column name is ambiguous across datasets. */
  private async disambiguate(sql: string, client?: McpClient): Promise<void> {
    const sets = this.vault.datasets();
    if (sets.length < 2) return;
    const counts = new Map<string, string[]>();
    for (const d of sets) {
      for (const c of d.columns) {
        counts.set(c.name, [...(counts.get(c.name) ?? []), d.table]);
      }
    }
    for (const [col, tables] of counts) {
      if (tables.length < 2) continue;
      const bare = new RegExp(`(?<![."\\w])${col}\\b(?!\\s*\\.)`, 'i');
      if (!bare.test(sql) || sql.includes(`."${col}"`) || sql.includes(`.${col}`)) continue;
      await this.ask(
        `"${col}" exists in ${tables.join(' and ')}. ` +
        'Qualify it in your query if this is not what you intended.',
        client,
      );
      return;
    }
  }

  /** Elicitation with a graceful fallback to a native confirm. */
  private async confirm(message: string, client?: McpClient): Promise<boolean> {
    if (client?.elicit) {
      try {
        const res = await client.elicit({ message });
        return res.action === 'accept';
      } catch { /* fall through */ }
    }
    return globalThis.confirm?.(message) ?? false;
  }

  private async ask(message: string, client?: McpClient): Promise<void> {
    if (client?.elicit) {
      try { await client.elicit({ message }); } catch { /* ignore */ }
    }
  }
}
```

Two design notes. The `effect()` in `init()` is what makes tool registration reactive — adding a dataset to the vault signal is the *only* thing needed to make its tools appear; nothing calls `registerTool` imperatively from the UI. And `query_<table>` re-reads the dataset from the vault on every call rather than closing over the stale `ds`, so semantic roles assigned after registration are respected.
